# 🏠 House Price Prediction

A machine learning web application that predicts the median house value based on housing and location-related features. The project uses an Artificial Neural Network (ANN) for regression, FastAPI for the backend, and HTML/CSS/JavaScript for the frontend.

The application is deployed and publicly accessible through Render.

## 🚀 Live Demo

**Live Application:**  
https://house-pred-77r1.onrender.com

**FastAPI Documentation:**  
https://house-pred-77r1.onrender.com/docs

## ✨ Features

- House price prediction using a trained ANN model
- FastAPI backend for model inference
- Interactive web interface for entering house details
- One-Hot Encoding for `ocean_proximity`
- Min-Max Scaling for input features
- Saved preprocessing objects using Pickle
- Trained Keras model for prediction
- REST API endpoint for predictions
- Deployed on Render

## 🧠 Machine Learning

This project uses an Artificial Neural Network (ANN) for regression.

The model predicts:

**`median_house_value`**

The input features are:

- Longitude
- Latitude
- Housing Median Age
- Total Rooms
- Total Bedrooms
- Population
- Households
- Median Income
- Ocean Proximity

### Ocean Proximity Categories

- `<1H OCEAN`
- `INLAND`
- `ISLAND`
- `NEAR BAY`
- `NEAR OCEAN`

## 🔄 Prediction Workflow

The application follows this pipeline:

**User Input → FastAPI → One-Hot Encoding → Feature Scaling → ANN Model → Prediction → Web Interface**

The saved OneHotEncoder and MinMaxScaler are reused during prediction to ensure that new input data is processed in the same way as the training data.

The encoder and scaler are transformed using `transform()` only during prediction; they are not fitted again.

Since this is a regression problem, classification accuracy is not used as the primary evaluation metric.

The model can be evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## 🔌 API

### POST `/predict`

The API accepts the following JSON input:

```json
{
  "longitude": -118.30,
  "latitude": 34.05,
  "housing_median_age": 25,
  "total_rooms": 3000,
  "total_bedrooms": 600,
  "population": 1200,
  "households": 500,
  "median_income": 5.25,
  "ocean_proximity": "NEAR OCEAN"
}
```

Example response:

```json
{
  "prediction": 261557.05
}
```

The prediction value represents the estimated median house value.

## 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/debmalyaa29/House_Pred.git
cd House_Pred
```

Create and activate a Python environment, then install the dependencies:

```bash
pip install -r requirements.txt
```

Start the FastAPI server:

```bash
uvicorn main:app --reload
```

Open the application at:

```text
http://127.0.0.1:8000
```

FastAPI interactive documentation is available at:

```text
http://127.0.0.1:8000/docs
```

## ☁️ Deployment

The application is deployed using Render.

The deployed application runs the FastAPI backend and serves the frontend, while the trained model and preprocessing objects are used to generate predictions from user input.

## 📌 Important Notes

- The model is used for educational and demonstration purposes.
- Predictions are estimates generated by a machine learning model and should not be treated as professional property valuations.
- The deployed Render service may take some time to respond after a period of inactivity.
